# أمن و سلامة

أرشيف رقمي صغير لمصنع حلويات العكر. يوثّق به الحارس من هاتفه البضائع الداخلة والبضائع الخارجة إلى الفروع ومخالفات العمال، مع الصور، وتبحث فيه الإدارة وتسترجع الصور بعد أشهر أو سنوات.

- واجهة عربية بالكامل (RTL)، وقابلة للتثبيت على الهاتف والحاسوب (PWA).
- الخادم يعمل على **Google Apps Script**، والصور محفوظة في **Google Drive** بشكل خاص، والسجلات في **Google Sheets**.
- لا يحتاج الحارس حساب Gmail، ولا يصل إلى Drive مباشرة.
- التكلفة صفر.

**الإعداد والتشغيل:** راجع [docs/SETUP.md](docs/SETUP.md).

## البنية

```
backend/    كود Apps Script (الخادم): الدخول، الصلاحيات، Drive، Sheets
frontend/   الواجهة (تُنشر على GitHub Pages)
tests/      محاكاة لخدمات Apps Script واختبارات تعمل محليًا
docs/       دليل الإعداد
```

| | الحارس | الإدارة |
|---|:-:|:-:|
| تسجيل بضاعة داخلة / خارجة / مخالفة مع الصور | ✓ | ✓ |
| «سجلاتي اليوم» للتأكد من الحفظ | ✓ | |
| الأرشيف والبحث والصور والتنزيل والطباعة | | ✓ |
| تعديل السجلات وحذفها (حذف قابل للاسترجاع) | | ✓ |
| الفروع والمستخدمون | | ✓ |

لكل حساب صلاحية (إدارة أو مستخدم) ووظيفة (حارس، سلامة الغذاء...). الوظائف تُدار من شاشة الإعدادات، ولكل وظيفة أنواع السجلات التي يستطيع صاحبها تسجيلها، دون تعديل الكود.

الواجهة بلغتين: العربية والإنجليزية، بزر في شاشة الدخول والشاشة الرئيسية، وتُحفظ اللغة على الجهاز. الترجمة في `frontend/js/i18n-en.js`، والنص العربي هو مفتاحها. رسائل الخادم تُترجم في الواجهة أيضًا، والاختبار `tests/i18n.test.js` يفشل إن أُضيف نص بلا ترجمة.

## التطوير المحلي

يكفي Node.js 18 أو أحدث، دون تثبيت أي حزم:

```bash
npm test                 # اختبارات الخادم على محاكاة Apps Script
npm run dev              # الواجهة + خادم محلي على http://localhost:8080
```

يطبع `npm run dev` كلمات المرور المؤقتة للحسابات التجريبية، وتُحفظ البيانات في الذاكرة فقط.

اختبار المتصفح الشامل (يحتاج Playwright):
```bash
node tests/e2e.js <مجلد فيه photo0.jpg وphoto1.jpg>
```

## الأمان

- لا يحتوي المستودع أي أسرار أو بيانات. معرّفات Drive وSheets والسر العام محفوظة في Script Properties داخل حساب Google.
- كلمات المرور مخزنة كبصمات SHA-256 مع ملح لكل مستخدم وسر عام وتكرار التجزئة.
- الجلسات: رمز عشوائي، يُحفظ في Sheets كبصمة فقط، ومدته 14 يومًا مع «تذكّرني» و12 ساعة بدونه.
- الخادم يتحقق من الجلسة والصلاحية في كل طلب، وصور المخالفات لا تُعرض إلا للإدارة، ويُسجَّل كل عرض لها.
